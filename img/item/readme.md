# 옷·아이템 그림

- 파일 이름: **`{id}_{나이 두 자리}.png`** — 상의 `top_01_09.png`(9살용) … / 하의 `bot_01_09.png` … / 기타(모자·가방·안경 등) `etc_01_09.png` …
  - 게임은 이로이 나이에 맞는 그림을 먼저 찾고, 없으면 가까운 나이(아래쪽 먼저), 그래도 없으면 나이 없는 `top_01.png`를 쓴다. 그래서 10살이 돼도 10살용이 없으면 9살용을 입는다.
- 이름·설명·가격·효과는 루트의 `item.csv`에 나이를 뺀 id(`top_01`)로 적는다. **`item.csv`에 적힌 아이템만 게임에 나온다.**
- **중요: 옷 그림은 `img/roy/`의 이로이 기본 사진과 똑같은 캔버스 크기(가로×세로)의 투명 PNG로, 이로이 몸에서 그 옷이 놓일 자리에 그려 둔다.** 게임은 기본 사진 위에 옷 그림을 그대로 겹쳐서 입힌다(크기·위치를 따로 맞추지 않음).
  - 가장 쉬운 방법: 기본 사진을 열고 그 위에 옷만 그린 레이어를 만든 뒤, 몸 레이어를 끄고 투명 PNG로 저장.
- 옷장 목록에서는 그림에서 투명한 부분을 자동으로 잘라내고 옷 부분만 작게 보여준다.
- 겹치는 순서: 몸 → 하의 → 상의 → 기타. 부위마다 하나씩 입을 수 있다.
- **지금 기본 사진 크기: 1187×896**(원본 2374×1792를 절반으로 줄임). 옷 그림은 이 크기로, 또는 원본 크기(2374×1792)처럼 **가로:세로 비율만 같으면** 크기가 달라도 정확히 겹쳐진다.
- 9·10·11살 사진은 키·몸 위치가 서로 달라서, 옷 하나를 모든 나이에 맞추려면 나이별로 위치를 맞춘 그림이 따로 필요하다(지금 코드는 나이와 상관없이 같은 `top_01.png`를 겹친다 — 나이별 옷 그림이 필요하면 말해 주세요).
- 2026-11-14 올린 9살용 15벌(상의 8·하의 7)은 옷만 찍은 **상품 사진 원본 그대로** 둔다. 몸 위치와 맞지 않아 지금은 `item.csv`에서 꺼 두었고, 옷을 입힌 캐릭터 사진 방식으로 다시 만들 예정.
