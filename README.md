# Roymaker (이로이 Maker)

프린세스 메이커 2 스타일의 생활 육성 시뮬레이션. 서울 성동구에 사는 초등학교 2학년 "이로이"의 등교·수업·학원·귀가 하루를 보낸다.

- 설계 문서: [`docs/design.md`](docs/design.md)
- 플랫폼: 웹 브라우저 (정적 HTML/JS, 빌드 도구 없음)
- 지도 엔진: **카카오맵 API** (JS SDK + 로컬 API 지오코딩, 확정) — 계정당 첫 앱은 카드 등록 없이 무료 쿼터 사용 가능. JS 키는 `index.html`에 그대로 박혀있음 — 카카오 JS 키는 구글 지도 키처럼 도메인 등록으로 보호하는 게 정상 사용법이라 공개 저장소에 있어도 된다. [카카오 디벨로퍼스](https://developers.kakao.com)에서 "사이트 도메인"을 등록해둘 것.
- **주의**: 앱 콘솔에서 JS 키를 발급받는 것과, 그 앱의 "카카오맵" 제품(OPEN_MAP_AND_LOCAL)을 활성화하는 건 별개 설정이다. 제품이 꺼져 있으면 SDK 요청이 403으로 거부된다 — 내 애플리케이션 → 제품 설정 → 카카오맵에서 활성화 필요.
- 좌표: 아직 지오코딩 전이라 `data/academies.json`은 실제 `lat/lng` 대신 `etaMinFromHome`(집에서 걸리는 분)으로 이동시간을 흉내냄. 지도 위 학원 마커는 집 좌표에서 이 값만큼 떨어진 임의 방향에 찍은 추정 위치(가상)다.
- 집 위치는 주소 지오코딩 대신 카카오 키워드 장소검색("e편한세상 금호파크힐스 113동")으로 잡는다 — 도로명주소 지오코딩은 단지 대표 좌표만 주지만, 카카오 지도는 대형 단지의 동별 위치를 개별 POI로 갖고 있어 113동 건물 위치에 더 가깝게 떨어진다.

## 폴더 구조

```
data/                학원·과목 등 콘텐츠 데이터 (DB 대신 JSON 테이블)
  academy_categories.json   학원 종류별 성장 규칙 (거의 안 바뀜)
  academies.json             실제 학원 인스턴스 (언제든 추가/삭제)
  subjects.json               교과목별 성장 규칙
  character.json              이로이 초기 상태
  items.json                   상점 아이템과 효과
  activities.json               방과후 활동(집안일·나들이 등)과 효과
docs/design.md        게임 설계 문서 전문
index.html            진입점 (정적 페이지)
style.css
main.js               일정 계획 + 하루 시뮬레이션 + 지도 렌더링
```

## 플레이 방법 (프린세스 메이커 2 스타일)

사이드바(캐릭터 카드 아래)의 **오늘 일정 · 학원정보 · 활동정보 · 지도 · 상점** 버튼으로 화면을 전환한다. 오른쪽은 한 번에 하나의 화면만 보여주는 탭 구조다.

1. **오늘 일정** 화면의 시간표(07:00–21:00)에 팔레트의 항목을 **드래그해서** 하루 일정을 짠다. 학교는 기본으로 09:00–16:00에 놓여 있고, 블록의 ×로 빼거나 팔레트에서 다시 끌어다 놓을 수 있다. 학원·활동도 원하는 시간대로 자유롭게 배치하고, 겹치는 시간에 놓으면 거부된다.
2. **학원정보** / **활동정보** 화면에서 각 학원·활동의 이름·시간·위치·효과를 미리 확인할 수 있다. 활동은 지금 집안일 돕기(30분/60분, 용돈벌이)와 나비정원 다녀오기(3시간, 서울숲 나비정원 — 감성·사회성 성장 + 스트레스 해소) 세 가지가 있다.
3. 일정을 다 짰으면 "일과 시작"을 누른다 — 시작하면 더는 바꿀 수 없고, 화면이 자동으로 **지도**로 바뀐다. 이동 구간마다 **도보 / 버스 / 지하철** 중 하나를 고른다. 도보는 **방향키(↑↓←→ 또는 WASD) 또는 지도 위 버튼**으로 직접 조작해야 하고(도착 반경 20m 안에 들어오면 자동으로 다음 블록으로 넘어감, 걷는 동안 체감 속도는 실시간 1초 = 게임 1분), 버스·지하철은 탑승 즉시 요금(450원)이 용돈에서 빠지고 자동으로 빠르게 데려다준다. 압구정 프리미엄 학원처럼 멀리 있는 곳은 도보 선택지가 아예 없다. 수업·학원 수업 시간 자체는 조작 없이 자동으로 빨리 감기된다.
4. 학교 도착이 09:00을 넘기면 지각 처리되고(버스·지하철 구간도 도착이 블록 시작시각보다 늦으면 동일하게 지각 처리), 학원을 다녀오면 그 학원 카테고리의 능력치가 오른다. 허기는 급식·저녁밥으로, 체력은 학원 활동으로 깎이고 휴식으로 회복된다. 걷는 동안 너무 오래 헤매거나 교통비가 부족해 버스/지하철을 못 타면 지각할 수 있다. 학교 블록을 아예 빼면 그날은 등교하지 않는다.
5. 하루가 끝나면 Day 카운터가 올라가고, 시간표는 "학교만 있는" 기본 상태로 초기화되어 다음 날 일정을 다시 짤 수 있다 — 능력치는 누적된다.
6. 학교·학원·활동 블록마다 스트레스가 쌓인다. **80을 넘기면 그 자리에서 몸살이 나서 그날 남은 일정이 전부 취소**되고 바로 귀가한다 — 하루에 너무 많이 몰아넣지 않도록 주의. 수면으로 매일 조금씩 회복되고, 나비정원 나들이처럼 쉬는 활동은 오히려 스트레스를 줄여준다.
7. **집안일 돕기**로 번 돈은 **상점**에서 책·운동화·간식 같은 아이템을 사서 바로 스탯/허기 효과로 바꿀 수 있다. 상점은 하루 진행 중엔 구매가 막혀 있고, 일정을 짤 때만 이용 가능하다.

현재는 교시별 퀴즈는 없고(§10 다음 단계 참고) 방과후 학원에서만 능력치가 성장한다.

## 로컬에서 열어보기

브라우저가 `fetch`로 로컬 JSON을 읽을 수 있도록 정적 서버로 띄워야 한다 (파일을 더블클릭해서 열면 CORS로 막힘).

```
npx serve .
# 또는
python -m http.server 8787
```
