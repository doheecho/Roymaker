이 문서는 게임 「이로이의 하루」 거리 모험에 들어간 **금호파크힐스 단지 지형 높이**를 정리한 것입니다.
새 건물·커뮤니티 시설·상가 3D 모델(GLB)을 만들 때 높이 기준으로 쓰세요. (2026-11-25, 게임 실제 계산값)

| 단지 밖 | 언제나 0층(평지) |

## 5. 새 모델을 만드는 두 가지 방법

### 방법 A — 바닥이 평평한 모델 (지금까지와 같음, 추천)
- 모델 바닥을 **Y = 0**에 평평하게 만듭니다. 높이(단차)는 **넣지 않습니다**.
- 게임이 모델의 각 부분을 그 자리 땅 높이만큼 자동으로 올려 줍니다(그 자리 경사를 그대로 따라감).
- 개별 동(아파트 한 동)처럼 작은 건물에 알맞습니다. 이미 있는 모델도 전부 이 방식이라 **다시 만들 필요가 없습니다.**
- 큰 모델(커뮤니티 시설처럼 100m가 넘는 것)은 경사를 따라 바닥·지붕이 살짝 기울어 보입니다(약 200m에 최대 8m 차이).

### 방법 B — 단차가 들어 있는 모델 (`terrain: "baked"`)
- 모델 안에 실제 단차(옹벽·계단·경사로·데크 높이)를 **위 4번 격자 높이대로 직접** 넣어 만듭니다.
- 높이 기준: 모델의 **Y = 0 = 단지 바깥 도로(0층)**. 예) 2층 높이 땅 = Y 6m.
- 맵 데이터에서 그 장소에 `terrain: "baked"`를 붙이면 게임이 높이를 다시 올리지 않습니다(이중으로 올라가지 않음).
  - 예: `{ id: 4, name: "금호파크힐스 104동", ..., model: "models/Community_north.glb", terrain: "baked" }`
- 단지 경계에 상가·필로티가 있어 바깥 도로와 단차를 메우는 구간(노란 표시 구역)을 표현하려면 이 방법을 쓰세요.
  모델 바깥 면은 0m(바깥 도로)부터 단지 높이까지 벽·상가 입면으로 채우면, 게임의 옹벽을 가려서 실제처럼 보입니다.

### 공통 규칙 (두 방법 모두)
- 단위: 1 = 1m, 위쪽 = +Y, 바닥 원점 = 모델 위치(x, z) 자리.
- 지금 쓰는 모델과 같은 자리·회전·배율이면 위 3번 표 값을 그대로 쓰면 됩니다(배율 1.3인 동은 모델을 1/1.3로 만들어야 실제 크기).
- 파일은 `models/place_이름.glb`로 올리면 깃허브가 자동으로 최적화·스카이뷰를 만듭니다.
- 텍스처는 1024px 이하, 메모·백업 데이터(extras)는 넣지 않는 게 좋습니다(자동으로 지워지긴 함).

## 6. 아직 게임이 하지 않는 것 (요청 시 참고)
- 캐릭터가 **모델 위 데크·계단을 밟고 올라가는 것**: 지금은 캐릭터 높이가 땅 높이(2번 점들의 보간)만 따라갑니다.
  방법 B 모델의 데크 높이가 땅 높이와 다르면 캐릭터가 데크 위가 아니라 땅 높이에 섭니다.
  → 데크 높이를 4번 격자와 비슷하게 맞추거나, 필요하면 "모델 바닥면을 밟게" 하는 기능을 따로 추가해야 합니다.
- 높이를 바꾸고 싶으면 맵 에디터의 "⛰ 지형 높이"에서 점의 층 수를 고치면 되고, 그러면 이 문서의 숫자도 바뀝니다.
