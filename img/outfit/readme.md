# 코디 세트 사진 (게임에서 사용)

- `img/roy_cloth/`의 코디 사진(원본)에서 배경 체크무늬와 반짝이 표시를 지우고 절반 크기(1187×896)로 줄인 것.
- 파일 이름: `roy_{n|g}_{나이}_{코디번호}.png` — `item.csv`의 `set_{코디번호}`와 짝. 예: `set_08` → `roy_n_09_08.png` / `roy_g_09_08.png`
- 코디를 입으면 기본 몸 사진 대신 이 사진을 통째로 보여준다. 방의 안경 상태에 맞는 사진을 먼저 쓰고, 없으면 다른 안경 사진, 그다음 가까운 나이 순.
- 지금 01번은 안경 사진만, 05번은 안경 없는 사진만 있다.
- 새 코디는 `img/roy_cloth/`에 원본을 올리면 같은 방법으로 투명화해서 여기에 넣는다.
