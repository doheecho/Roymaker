### 1-3. 성장 배율 규칙 (`growthMultiplier()`)
```
if (허기 ≤ 30 또는 기력 ≤ 20) → 성장 배율 0.5
else → 1.0
```
- `LOW_HUNGER = 30`, `LOW_ENERGY = 20`
- 배율이 0.5일 때 능력치 증가분은 **확률 반올림**으로 계산한다: `+1`이면 50% 확률로 0 또는 1, `+3`이면 50:50으로 1 또는 2가 된다. 실제로 깎였으면 로그에 "배고프거나 지쳐서 덜 자랐다"가 덧붙는다.
- 스탯이 아닌 `wallet`/`hunger`/`staminaNow`/`stress`는 배율 영향을 받지 않는다. `delinquency`(비행화)도 깎이지 않는다.
- 상점 구매 효과는 배율 적용 안 됨(`applyEffect(effect, { modifier: false })`).

### 6-3. 등록 · 수업 메커니즘
- **매주 일정을 미리 등록**: 학원정보 화면에서 학원마다 요일(월~금)·시작 시각을 고른다. 선택 가능한 시작 시각은 `운영시간 open ~ (close − 60분)` 사이에서 **1시간 단위**로만 — 운영시간 밖엔 애초에 등록 불가.
- 등록은 **다음 주 월요일부터 적용**된다(`state.registrations.pending` → 월요일에 `active`로 확정, 로그: `"📋 새 주가 시작됐다 — 미리 등록한 학원 일정이 이번 주에 적용된다"`). 상태 표시: `"이번 주 등록: {요일} {시각}"` 또는 `"이번 주: {현재} → 다음 주(월)부터: {예정}"` (등록 안 했으면 `"등록 안 함"`).
- 운영시간 안이지만 **등록하지 않은 시간**에 가면 **자율학습**: 집중력 +1, 성실성 +1, 기력 −3(`AUTONOMOUS_STUDY_EFFECT`), 허기 −10, 스트레스 +6(`AUTONOMOUS_STUDY_STRESS`). 로그: `"{학원명} — 등록된 수업 시간이 아니라 자율학습을 했다 ({효과})"`, 일기: `"{학원명}에 갔는데 내 수업 시간이 아니라서 혼자 자습을 했다."`
- **등록 수업**이면: 카테고리 성장 적용, 기력 −`staminaCost`, 허기 −15, 스트레스 +18(`ACADEMY_STRESS`). 로그: `"{학원명} 등록 수업 완료 — {효과}"`, 일기: `"{학원명}에서 열심히 수업을 들었다."`
- 수업이 끝나면 선택창: **"{학원명} 끝 — 어떻게 갈까요?"**
  - `🚌 하원버스 타고 집으로` → `rideTransit`으로 곧장 집까지 이동(요금 없음). 로그 `"하원버스 탑승"` → `"하원버스로 집 도착"`, 일기 `"수업이 끝나고 하원버스를 타고 집에 왔다."`
  - `🚶 하원버스 안 타고 개별 이동` → 로그 `"하원버스를 타지 않고 개별적으로 이동한다"`, 이후 다음 일정으로 평소처럼 도보/대중교통 이동

- 구매 피드백: `"{아이콘} {이름}을(를) 샀다! {효과} (잔액 {용돈}원)"`

## 9. 주간 일정 짜기 (드래그 앤 드롭)

- 평일에 보고 있으면 **그 주 월~금 5칸**, 주말에 보고 있으면 **오늘 하루만** 보여준다(`plannerDays`).
- 편집 가능 조건(`isDayEditable`): **오늘 이후의 날짜 AND 일과가 진행 중이 아닐 때**만. 지난 날짜는 잠김.
- 기본 블록(`buildDefaultBlocks`): 등교일이면 정규수업 블록 자동 추가 + 그 요일에 등록된 학원 수업 자동 추가(겹치면 등록 수업 생략).
- 드래그 배치 시 유효성 검사(`rangeForSpec`):
  - **정규수업**: 방학 중이면 배치 불가(`invalid`)
  - **방과후**: 평일 아니거나 방학 중이면 배치 불가
  - **늘봄**: 슬롯이 `vacationOnly`면 방학 중에만, 아니면 방학 아닐 때만 가능. 오후돌봄은 시작 시각이 자동 계산(앞 수업 끝나는 시각 ~ 다음 일정 시작 전까지)
  - **학원/활동**: 운영시간(`hours`)을 벗어나면 배치 불가
  - **공통**: 하루 끝(21:00, `DAY_TIMELINE_END_MIN`)을 넘기면 배치 불가
- 겹치는 시간대에 놓으면 거부되고 시간표가 흔들리는 "거부" 애니메이션(`flashReject`)이 뜬다.
- 날짜 헤더에 공휴일/방학 이름이 태그로 표시된다(`dayHeaderInfo`).

## 10. 하루 실행 ("일과 시작" ~ "잠자기")

### 10-1. 이동 — 걷다가 정류장/역을 만나면 선택
- 이동은 **항상 방향키/터치로 직접 걷는 것**으로 시작한다. 출발 전에 수단을 고르는 창은 없다.
- 걷다가 버스정류장(🅱) 또는 지하철역(🅂)의 반경(**20m**, `ARRIVAL_RADIUS_M`) 안에 들어오면 그 자리에서 멈추고 선택창이 뜬다: **"{정류장/역 이름} 도착 — 버스/지하철을 타고 어디로 갈까요?"**
  - 그 정류장/역을 제외한 **같은 유형의 나머지 모든 정류장/역**이 선택지로 나열됨 (요금 450원, 용돈 부족하면 비활성화)
  - `"그냥 걷기"` 선택 시 타지 않고 계속 걷는다
  - 탄 경우: 요금 즉시 차감, 로그 `"{버스/지하철} 요금 450원 지불 (잔액 {용돈}원)"`, 애니메이션 이동(거리 220m당 게임 1분, 최소 5분, 실제 연출 1.8초) 후 로그 `"{시각} {도착지} 도착"`
  - 한 번 "그냥 걷기"를 고르거나 내린 정류장/역은 **그 자리를 벗어나기 전까지 다시 묻지 않는다**
- 정류장·역이 전혀 없는 길은 목적지까지 끝까지 도보로 간다(거리 제한 없음, 멀면 오래 걸릴 뿐).
- 도보 속도: **60m/s**(`MOVE_SPEED_MPS`), 걷는 동안 게임 시계는 실시간 1초 = 게임 1분(`GAME_MIN_PER_REAL_SEC`).
- 버스/지하철 요금: 둘 다 **450원**(`BUS_FARE`/`SUBWAY_FARE`).

### 10-2. 지각 판정
- 목적지 도착 시각이 각 블록의 "지각 기준 시각"(`lateThresholdFor`)을 넘으면 지각:
  - 정규수업 블록 → 08:50(`SCHOOL_LATE_MIN`)
  - 늘봄 아침돌봄 → 09:00(`MORNING_CARE_LATE_MIN`)
  - 그 외(학원/방과후/활동/늘봄 다른 슬롯) → 그 블록의 시작 시각
- 로그: `"{시각} {장소} 도착 — 지각"` (지각 아니면 "— 지각" 생략)
- 학교 지각이면 성실성 −1 패널티 적용(§3-1).

### 10-3. 스트레스 · 몸살
- 블록을 소화할 때마다 스트레스가 쌓인다: 정규수업 +10, 학원 등록수업 +18, 학원 자율학습 +6, 방과후 +8, 늘봄 슬롯별 시간당 1~2, 활동/돌발사건/핫플레이스는 각자의 `effect.stress` 값(음수면 오히려 감소).
- **스트레스 ≥ 80**(`STRESS_ILLNESS_THRESHOLD`)이 되는 순간: 그 자리에서 몸살이 나서 **남은 일정이 전부 취소**되고 바로 귀가 처리.
  - 스트레스 −40(`STRESS_ILLNESS_RELIEF`) 즉시 완화
  - 로그: `"스트레스가 너무 쌓여 몸살이 났다 — 나머지 일정을 취소하고 집으로 돌아갔다"`
  - 일기: `"너무 무리했는지 몸살이 나서 남은 일정을 못 하고 집에 왔다."`
  - 하루 요약에 `" 너무 무리해서 몸살이 났다."` 덧붙음

### 10-4. 일정 도중 집으로 — 취소 확인
- 집이 아닌 곳으로 가는 도보 구간에서, 집을 벗어났다가 다시 집 반경(20m) 안으로 들어오면 그 자리에서 멈추고 확인창: **"일정을 취소하고 집에 들어갑니다"** — `예` / `아니오`
  - `아니오` → 가던 길 계속
  - `예` → `DayCancelledEarly` 발생, 그날 남은 블록 전부 취소, 로그 `"{시각} 일정을 취소하고 집으로 돌아왔다"`, 일기 `"가던 길에 마음이 바뀌어서 남은 일정을 취소하고 집으로 돌아왔다."`
  - 이어서 선택창: **"집에서 무엇을 할까요?"** — `chore_30`/`chore_60`(집안일 돕기) 또는 `"그냥 쉬기"`
    - 활동 선택 시 그 효과 바로 적용
    - `"그냥 쉬기"` → 로그 `"{시각} 그냥 쉬었다"`, 일기 `"집에서 뒹굴뒹굴 쉬었다."`
  - 하루 요약에 `" 도중에 일정을 취소하고 집에 돌아왔다."` 덧붙음
  - **퇴근 후 어디로 갈지 선택하는 기능 등 그 다음 단계는 아직 미구현**

### 10-5. 하루 요약 · 일기
- 하루 끝나면: 허기 90으로 회복, 기력 +10(최대 100), 스트레스 −(일정 없었으면 30 / 있었으면 15) 회복. 로그: `"저녁밥을 먹고 하루를 마쳤다"`
- 하루 요약 문장 조합: `"Day {N} 완료 — {학교파트}{몸살파트}{취소파트} {변화파트} 허기 {값} · 기력 {값} · 스트레스 {값}"`
  - 학교파트: `"학교에 지각했다."` / `"학교에 정시 등교했다."` / `"오늘은 학교를 가지 않았다."`
  - 변화파트: `" 오늘의 변화: {스탯 변화 목록}."` 또는 `" 오늘은 능력치 변화가 없었다."`
- **일기 화면** ([오늘의 일기] {날짜}): 그날 모은 일기 문장들(없으면 `"오늘은 별일 없이 조용히 지나갔다."`) + 마무리 한 줄(`diaryClosing`):
  1. 몸살 났으면 → `"몸이 안 좋아서 오늘은 일찍 자야겠다. 내일은 꼭 나아야지."`
  2. 스트레스 ≥ 60 → `"오늘은 정말 정말 피곤한 하루였다. 푹 자고 싶다."`
  3. 스트레스 ≤ 20 → `"오늘도 즐거운 하루였다! 내일은 또 무슨 일이 생길까?"`
  4. 기본값 → `"오늘 하루도 끝! 내일도 힘내자."`
  - 날씨는 `(Day × 7 + 3) % 6`으로 고정 순환: ☀️ 맑음 / ⛅ 구름 조금 / ☁️ 흐림 / 🌧️ 비 / 🌬️ 바람 / 🌈 맑게 갬
  - **😴 잠자기** 버튼 → 화면이 어두워졌다가(Zzz…) 다음 날 "오늘 일정" 화면으로. 이때 날짜가 넘어가고 자동 저장됨.

## 11. 돌발사건 (`data/events.json`, 걷는 동안 발생)

### 11-1. 발생 조건
- 실제로 걷는 동안(멈춰 있으면 판정 안 함), **실제로 걸은 게임 1분마다** 확률 판정
- 확률: **7%**(`EVENT_CHANCE_PER_MIN`)
- 쿨다운: 이전 이벤트 이후 **6분**(`EVENT_COOLDOWN_MIN`) 지나야 재판정
- 하루 최대 **3번**(`MAX_EVENTS_PER_DAY`)
- 이벤트 종류는 `weight`(가중치)로 추첨되며, `locationBoost: {placeName, radiusM, multiplier}`가 있으면 그 장소 반경 안에 있을 때 가중치가 그만큼 곱해진다(현재는 `butterfly_uncle`만 해당).
- 스탯 체크가 있는 선택지(`check: {stat, threshold}`)의 성공 확률 공식: `chance = min(0.9, max(0.1, 스탯값 / (threshold × 2)))`

### 11-2. 이벤트 전체 7종

**😠 일진 어린이를 만났다!** (`bully`, 가중치 2)
> 덩치 큰 형이 길을 막고 "용돈 좀 내놔"라고 한다.
- 💪 맞서 싸운다 (근력 체크, threshold 30)
  - 성공: "용기 있게 맞서자 형이 슬금슬금 물러났다!" — 인싸력 +2, 자존감 +2, 기력 −5, 스트레스 +5 (5분)
  - 실패: "힘에서 밀려 용돈을 빼앗겼다… 어른께 꼭 말씀드리자." — 용돈 −1000, 자존감 −2, 기력 −10, 스트레스 +15 (5분)
- 🏃 도망간다 → "있는 힘껏 달려서 도망쳤다. 휴, 숨차다!" — 순발력 +1, 기력 −6, 스트레스 +5 (3분)

**😢 곤란한 친구를 만났다** (`poor_friend`, 가중치 2)
> 친구가 넘어져서 무릎을 다치고 울고 있다.
- 🤝 돕는다 → "친구를 일으켜 주고 가까운 어른에게 함께 가 주었다. 친구가 고맙다고 했다!" — 사회성 +2, 자존감 +2, 스트레스 −3 (10분)
- 🚶 그냥 간다 → "모른 척 지나왔지만 마음이 계속 쓰인다…" — 비행화 +1, 스트레스 +3 (0분)

**🪙 길에서 돈을 주웠다** (`found_coin`, 가중치 2)
> 길바닥에 {100/500/1000 중 랜덤}원이 떨어져 있다. 주인은 보이지 않는다.
- 주머니에 넣는다 → "{금액}원이 생겼다!" — 용돈 +{금액} (0분)

**👋 친구를 우연히 마주쳤다** (`friend_meet`, 가중치 3)
> 같은 반 친구가 "어? 로이다!" 하고 손을 흔든다.
- 🎈 함께 놀러간다 → "친구랑 신나게 놀다 보니 30분이 훌쩍 지났다!" — 사회성 +3, 스트레스 −10, 기력 −5 (30분)
- 😊 반갑게 인사한다 → "반갑게 인사하고 각자 갈 길을 갔다." — 사회성 +1, 인싸력 +1 (1분)
- 🙈 모른척 지나간다 → "못 본 척 지나갔다. 친구가 서운해할지도…" — 사회성 −1, 인싸력 −1 (0분)

**🕴️ 수상한 어른이 말을 걸었다** (`stranger`, 가중치 1)
> 처음 보는 어른이 "맛있는 거 사줄게, 아저씨랑 같이 가자"라고 한다.
- (안전 교육을 듣기 전엔 아래 두 선택지만 보임, 자물쇠 표시: `requiresSafety` = "학교 창의적 체험활동 '안전 교육'을 들으면 고를 수 있어요")
- 🍭 따라간다 → ⚠️위기: "낯선 곳으로 끌려갈 뻔했다 — 지나가던 경찰 아저씨가 발견해 무사히 구해 주었다. 너무 무서웠다…" — 스트레스 +30, 기력 −10, 자존감 −2 (20분)
- 😶 머뭇거린다 → ⚠️위기: "어쩔 줄 몰라 머뭇거리는 사이 손목을 잡혔다 — 주변 어른이 소리쳐서 겨우 벗어났다." — 스트레스 +25, 기력 −8 (15분)
- 🙅 "싫어요! 안 가요!" 크게 외치고 사람 많은 곳으로 간다 (안전교육 이수 시만) → "안전교육 때 배운 대로 큰 소리로 거절하고 가게 안으로 들어갔다. 가게 어른이 칭찬해 주셨다!" — 성실성 +1, 자존감 +2, 스트레스 +5 (5분)
- 📱 엄마에게 전화한다 (안전교육 이수 시만) → "'엄마! 모르는 아저씨가 따라오래!' 전화하자 수상한 어른이 슬그머니 사라졌다. 엄마가 잘했다고 했다." — 자존감 +3, 스트레스 +5 (5분)

**🔎 분실물을 주웠다** (`lost_item`, 가중치 2)
> 길에서 누군가 잃어버린 {스마트폰(3000원)/지갑(5000원)/돈 봉투(3000원) 중 랜덤}을(를) 주웠다.
- 🚓 경찰서에 갖다준다 → "{물건}을(를) 경찰서에 맡겼다. 경찰 아저씨가 칭찬해 주셨고, 소문이 나서 친구들 사이에서 인기가 올랐다!" — 사회성 +2, 인싸력 +2, 자존감 +3 (15분)
- 🤫 내가 가진다 → "{물건}을(를) 몰래 챙겼다. 안에 있던 {금액}원이 생겼지만 마음이 영 불편하다…" — 용돈 +{금액}, 비행화 +3, 스트레스 +10 (0분)

**🦋 나비정원 삼촌을 만났다!** (`butterfly_uncle`, 가중치 1, **강동역 1km 이내에서 가중치 ×12**)
> 저 멀리서 낯익은 얼굴이 보인다 — 나비정원에서 늘 반갑게 맞아주시던 삼촌이다!
- 😊 반갑게 다가간다 → "'우리 로이 아니야? 이게 얼마만이야!' 삼촌이 환하게 웃으며 용돈 {3000/5000/7000 중 랜덤}원이랑 간식을 잔뜩 안겨주셨다 — 스타벅스 과자, 뚜레쥬르 빵, 파리바게뜨 미숫가루까지!" — 용돈 +{금액}, 스트레스 −15, 사회성 +2, 자존감 +2, 기력 +10 (10분)

**🙂 낯익은 아저씨를 만났다** (`gyeongyul_uncle`, 가중치 2, 순수 랜덤)
> 저쪽에서 어떤 아저씨가 로이를 보고 손을 흔든다. 어? 경율이 삼촌 맞나…?
- 🤔 긴가민가하며 다가간다 → "'로이야! 많이 컸네!' 경율이 삼촌이 맞았다! 반가운 마음에 삼촌이 용돈 {2000/3000/5000 중 랜덤}원을 쥐여주셨다." — 용돈 +{금액}, 사회성 +2, 자존감 +2 (5분)

## 14. 부모님 회사 방문 & 설득 전화 (`data/phone.json` `companyVisit`)

- 장소: 삼성메디슨(`place.csv` P행, 강동역 바로 근처), 반경 **300m**(`radiusM`), 하루 **1번**(`state.companyVisitedToday`)
- **아빠**에게 전화하면 바로: `"{이름}! 나 지금 {이름} 회사 앞이야. 잠깐 나와 줄 수 있어?"` → `"뭐? 로이가 여기까지 왔다고? 금방 나갈게!"` → 간식 선물
  - 기본 효과: 스트레스 −8, 자존감 +1 + 아래 간식 3개(랜덤) 효과 합산, 소요 15분
  - 간식 6종(그중 3개 랜덤 지급): 🥛우유(기력+5,허기+8) · 🍞빵(허기+15,기력+3) · 🥤미숫가루(기력+8,허기+10) · 🍬젤리(스트레스−6) · 🍪스타벅스 과자(스트레스−6,허기+6) · 🍌바나나(기력+8,허기+8)
  - 로그: `"🏢 삼성메디슨 앞 — {이름}이/가 나와서 간식을 줬다: {간식명들} ({효과})"`
  - 일기: `"삼성메디슨 앞에서 {이름}에게 전화했더니 {이름}이/가 회사에서 나왔다! 회사 식권으로 받은 {간식들}을(를) 간식으로 선물해 줘서 맛있게 먹었다."`
- **엄마**에게 전화하면 선택창: **"{시각} · 삼성메디슨 근처다. 엄마에게 뭐라고 할까요?"**
  - `🍪 회사 앞으로 잠깐 나와줄 수 있어?` → 위 아빠와 동일한 간식 방문 흐름
  - `🏃 엄마, 빨리 퇴근하고 나랑 놀자!` → **설득 전화**:
    - 성공 확률 공식: `chance = min(0.9, max(0.1, 논리 스탯 / 40))` (기준치 20, `logicThreshold`)
    - **성공** → `"정말? 알았어, 엄마가 오늘은 특별히 서둘러서 일찍 퇴근할게! 이따 집에서 꼭 안아줄게 💕"` — 스트레스 −10, 자존감 +3, 사회성 +1
    - **실패** → `"로이야 미안해, 엄마 아직 회사에서 할 일이 남았어. 이따 퇴근하고 꼭 같이 놀자! 사랑해 💕"` — 스트레스 −2
    - **퇴근 후 어디로 갈지 직접 고르는 기능은 아직 미구현**
  - `📵 그냥 끊는다` → 아무 일도 안 일어남

## 18. 저장 · 불러오기

- 저장 키: `localStorage["roymaker-save-v2"]` (`SAVE_KEY`)
- 하루가 끝나거나(다음 날로 넘어갈 때), 학원 등록을 바꾸거나, 상점에서 구매할 때마다 자동 저장된다(`saveGame()`).
- 저장된 게임을 불러오면: 로컬에서 왔으면 `"💾 이 기기에 저장된 진행 상황(Day {N})을 불러왔어요."`, 클라우드에서 왔으면 `"☁️ 클라우드에 저장된 진행 상황(Day {N})을 불러왔어요."`
- **🔄 새 게임 (저장 지우기)** 버튼: 확인창 `"저장된 진행 상황을 지우고 Day 1부터 새로 시작할까요?"` → 확인 시 로컬 저장 삭제(+클라우드 연결돼 있으면 클라우드 문서도 삭제) 후 페이지 새로고침. 하루 진행 중에는 비활성화.
- **여러 기기 공유(선택, 2026-11 추가)**: 루트의 `firebase-config.js`에 Firebase 프로젝트 설정값(`apiKey` 등 6개, 카카오 키처럼 공개돼도 되는 값)을 채우면 Firestore `saves/{CLOUD_SAVE_ID}`("iroi") 문서 하나를 모든 기기가 공유한다. 설정 방법·Firestore 보안 규칙은 README.md "여러 기기에서 세이브 공유" 절 참고.
  - 시작 시 순서(`main()`): `initCloudSave()`(SDK 동적 로드 + 익명 로그인, 데이터 로딩과 병렬 진행) → 클라우드 연결됐으면 `loadFromCloud()` 먼저 시도 → 없으면 `loadGame()`(로컬)로 폴백, 이때 로컬에 기존 세이브가 있고 클라우드가 비어 있으면 `saveGame()`을 한 번 더 호출해 로컬 세이브를 클라우드로 올려준다(최초 마이그레이션).
  - `saveGame()`은 항상 로컬(`localStorage`)에 먼저 쓰고, `state.cloud.ready`면 같은 데이터를 Firestore에도 `.set()`한다 — 둘 중 하나가 실패해도 나머지 한쪽은 정상 저장된다.
  - `firebase-config.js`의 `apiKey`가 비어 있거나, SDK 로드/인증이 실패하면(`FirebaseError` 등) `state.cloud.ready`가 `false`로 남고 콘솔에 경고만 찍힌 채 평소처럼 로컬 전용으로 동작한다 — 설정 실수로 게임이 멈추지 않는다.
