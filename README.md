# Roymaker (이로이 Maker)

프린세스 메이커 2 스타일의 생활 육성 시뮬레이션. 서울 성동구에 사는 초등학교 2학년 "이로이"의 등교·수업·학원·귀가 하루를 보낸다.

- 설계 문서: [`docs/design.md`](docs/design.md)
- 게임 안의 모든 조건·선택지·메시지 전체 목록: [`docs/game-content.md`](docs/game-content.md) — 업데이트 요청할 때 참고용
- 플랫폼: 웹 브라우저 (정적 HTML/JS, 빌드 도구 없음)
- 지도 엔진: **카카오맵 API** (JS SDK + 로컬 API 지오코딩, 확정) — 계정당 첫 앱은 카드 등록 없이 무료 쿼터 사용 가능. JS 키는 `index.html`에 그대로 박혀있음 — 카카오 JS 키는 구글 지도 키처럼 도메인 등록으로 보호하는 게 정상 사용법이라 공개 저장소에 있어도 된다. [카카오 디벨로퍼스](https://developers.kakao.com)에서 "사이트 도메인"을 등록해둘 것.
- **주의**: 앱 콘솔에서 JS 키를 발급받는 것과, 그 앱의 "카카오맵" 제품(OPEN_MAP_AND_LOCAL)을 활성화하는 건 별개 설정이다. 제품이 꺼져 있으면 SDK 요청이 403으로 거부된다 — 내 애플리케이션 → 제품 설정 → 카카오맵에서 활성화 필요.
- 좌표: 학원 5곳 중 4곳(태비KTS태권스쿨·아담리즈수학·씨앤에이논술·창의코딩랩·하이파이브미술학원)과 활동(외할머니댁 심부름·중계동 심부름·불암산 나비정원)은 실제 주소를 런타임에 지오코딩한다. 압구정 프리미엄 아카데미만 아직 주소가 없어 `etaMinFromHome` 기반 가상 위치를 쓴다. 지오코딩이 실패하면 전부 같은 방식(집 좌표에서 거리·방향 오프셋)으로 자동 대체된다.
- 버스정류장·지하철역은 루트의 `place.csv`(유형·이름·위도·경도)에서 좌표를 그대로 읽는다 — 지오코딩하지 않는다. 유형 **B**는 버스정류장(파란 원), **S**는 지하철역(보라 원)으로, 동그라미 안에 유형 알파벳을 넣은 아이콘과 이름 레이블로 지도에 표시된다. 노선 순서는 없고, 같은 유형끼리는 어느 곳으로든 바로 이동할 수 있다(요금 450원). 행을 추가하면 다음 실행부터 바로 반영된다.
- **일정 짜기 팔레트**: 항목은 아이콘과 이름만 보이고, 시간·운영시간·효과는 마우스를 올리면 말풍선으로 보인다. 집안일은 "집안일 30분"·"집안일 1시간".
- **계획을 어긴 날 저녁 엄마와 대화**: 일정 도중 집으로 들어와 남은 일정을 빼먹으면 저녁에 엄마가 이유를 묻는다. 최근 7일 사이 **논리가 2 이상 올랐으면** 이로이가 타당한 이유를 설명하고 엄마가 걱정하며 잘했다고 해 준다(스트레스 −10, 기력 +10). 아니면 이유 없이 약속을 어겼다고 꾸중(스트레스 +10, 비행화 +2). 그 뒤 자유 시간 메뉴가 이어진다.
- **저장/불러오기 (20칸)**: 화면 오른쪽 위 **💾 저장 / 📂 불러오기** 버튼으로 최대 20칸에 저장하고 원하는 칸을 불러온다(Day·날짜·용돈·저장 시각 표시, 덮어쓰기/불러오기 전에 확인). 일과 진행 중에는 막혀 있다. 슬롯은 이 브라우저에 저장되고, 자동 저장(하루가 끝날 때)은 그대로 따로 동작한다.
- **일정이 끝난 뒤 자유 시간**: 오늘 일정을 다 마치고 집에 오면(도중에 일정을 취소하고 집에 들어와도) 이로이가 "오늘 일정이 다 끝났다! 이제 뭘 할까?" 하고 묻는다 — **밖에 나가서 논다**(다시 지도를 자유롭게 걸어 다니고, 집에 돌아오면 끝. 돌발사건·핫플레이스·전화·버스도 그대로), **집에서 숙제를 한다**(1시간, 과목은 랜덤, 학교 수업의 절반만큼 능력치 + 성실성·자존감 +1), **집에서 게임을 한다**(1시간, 스트레스 −10. 하루 2시간 이상 하면 엄마나 아빠에게 꾸중 + 비행화 +1), **그냥 잔다**(오늘의 일기로). 밤 10시가 되면 자동으로 잠자리에 든다. 몸살이 나서 돌아온 날은 바로 잔다.
- **수상한 어른 신고**: 수상한 어른을 만난 자리에서 100m 안에서 📱로 112에 걸면 신고 대화가 나오고 사회성 +1·자존감 +2·언어 +1·논리 +1(장난전화 비행화 대신). 엄마·아빠에게 걸면 울먹이며 이야기하고 부모님이 걱정하며 달래 준다(스트레스 −6, 자존감 +1). 문구는 `phone.json`의 `strangerReport`.
- **가게·놀이터 반응**: 문구점·분식집에서 사거나 놀이터에서 놀면 이로이가 "와 진짜 맛있다! 엄청 맵고 짜!" 같은 소감을 말한다(`hotplaces.json`의 `reaction`). 놀이터 친구의 제안을 거절하면 "아니야~ 나는 지금 학교에 가야 해. 다음에 즐겁게 놀자~", 받아들이면 "그래! 재미있겠다 나도 같이 놀자~".
- **설명보기**: 화면마다 긴 설명은 제목 오른쪽 **❓ 설명보기** 버튼을 누르면 팝업으로 뜬다(바깥을 누르거나 Esc로 닫힘).
- **대화창**: 모든 선택·대화(돌발사건, 핫플레이스, 휴대전화, 버스/지하철, 하원버스, 집 앞 확인 등)는 프린세스 메이커 2 메시지 창처럼 남색 바탕에 금색 이중 테두리를 두른 창이 지도 아래쪽에 뜬다. 왼쪽 액자에 **말하는 사람의 얼굴**(이로이는 얼굴 그림, 엄마·아빠·친구·외할머니·경찰관·동네 형·수상한 어른·문구점 아저씨·분식집 이모·선생님·삼촌들은 `portraits.js`에서 코드로 그린 도트 얼굴)과 이름표가 나오고, 대사는 한 글자씩 써지며(창을 누르면 바로 다 보임) 다 써진 뒤 선택지가 나타난다. 누가 말할지는 `events.json`의 `speaker`/`resultSpeaker`, `hotplaces.json`의 `speaker`/`greeting`, 휴대전화는 연락처 id로 정해진다.
- **일정 애니메이션**: 학교 교시·급식·자율독서·중간놀이, 방과후, 늘봄, 학원, 집안일·심부름·나비정원 같은 일정이 진행되는 동안 지도 오른쪽 위에 액자 창이 떠서 그 일정에 맞는 도트 애니메이션을 보여 준다(`scenes.js`) — 교실 칠판(과목별 글씨), 급식, 책 읽기, 놀이터, 축구, 피구, 줄넘기, 인라인, 댄스, 태권도 발차기, 그림 그리기, 클레이·요리, 악기 연주, 컴퓨터 코딩, 과학 실험, 공부 책상(과목별 기호), 청소, 심부름 길, 나비정원, 잠자기. 장면을 보여 주느라 교시 하나는 약 1.4초, 학원·활동은 약 3초씩 진행된다.
- **걷는 캐릭터**: 지도 위 이로이는 코드로 그린 24×35 도트 스프라이트(얼굴 그림처럼 검은 앞머리·동그란 금테 안경·웃는 눈·발그레한 볼·민트색 티셔츠, 주황 책가방)에 고전 RPG 필드 캐릭터처럼 진한 외곽선을 둘렀다. 방향키에 맞춰 앞·뒤·왼쪽·오른쪽을 바라보고(대각선은 좌우 우선), 걷는 동안 팔다리가 사인 곡선으로 부드럽게 앞뒤로 흔들리는 8프레임 걸음(걸음마다 몸이 살짝 들썩임)이 나오며, 멈추면 서 있는 자세로 돌아간다. 버스·지하철·하원버스를 타는 동안은 머리 위에 🚌/🚇 말풍선이 뜬다. 색은 `main.js`의 `SP` 팔레트에서 바꿀 수 있다.
- 지도 아이콘: 우리집(CSV의 H 행)과 금북초는 **네모 아이콘 안에 "우리집"·"금북초"**, 나머지는 동그라미 안 글자 + 이름 레이블 — **B** 버스정류장, **S** 지하철역, **A** 학원, **P** 장소(할머니댁·부모님 회사·극동미라주·문구점·분식집·놀이터).
- 우리집 좌표는 CSV의 H 행을 그대로 쓰고, 활동은 `activities.json`의 `place` 값과 같은 이름의 P 행 좌표를 쓴다. **학원은 CSV에 유형 `A`로, `academies.json`의 학원 이름과 똑같은 이름**을 넣으면 지오코딩 대신 그 좌표를 쓴다.
- 집 위치는 주소 지오코딩 대신 카카오 키워드 장소검색("e편한세상 금호파크힐스 113동")으로 잡는다 — 도로명주소 지오코딩은 단지 대표 좌표만 주지만, 카카오 지도는 대형 단지의 동별 위치를 개별 POI로 갖고 있어 113동 건물 위치에 더 가깝게 떨어진다.
- **지도 화면**은 제목과 지도만 보이고 조작법 설명 문단은 없다. 레이아웃은 `main`을 `align-items: stretch`로 둬서, 오른쪽 패널(지도 포함)의 아랫단이 왼쪽 상태창의 아랫단과 항상 맞춰진다 — 상태창은 `align-self: start` + `height: fit-content`로 자기 콘텐츠 높이만 차지해서, 긴 목록(학원정보 등)이 떠 있을 때는 거꾸로 오른쪽이 더 길어지고 왼쪽은 그대로다.

## 플레이 방법 (프린세스 메이커 2 스타일)

사이드바(캐릭터 카드 아래)의 **오늘 일정 · 학원정보 · 활동정보 · 지도 · 상점** 버튼으로 화면을 전환한다. 오른쪽은 한 번에 하나의 화면만 보여주는 탭 구조다.

1. **주간 일정** 화면에서 **매주 월요일에 월~금 한 주 일정**을 짠다. 시간표는 가로로 월·화·수·목·금 5칸(세로는 07:00–21:00, 30분 단위)이고, 팔레트 항목을 원하는 **요일 칸의 시간**에 끌어다 놓는다. 등교일엔 정규수업과 이번 주에 등록한 학원 수업이 기본으로 들어가 있고, 공휴일·방학은 칸 머리에 표시되고 학교가 자동으로 올라가지 않는다. 지난 요일은 잠기고, **오늘과 남은 요일은 그날 일과를 시작하기 전(당일 아침)까지 고칠 수 있다.** 주말(토·일)에는 그날 하루 칸만 나온다. 주간 계획도 자동 저장된다. 게임은 **2026년 3월 1일(일), Day 1**부터 시작한다.
2. **학원정보** / **활동정보** 화면에서 각 학원·활동의 이름·시간·위치·효과를 미리 확인할 수 있다. 활동은 지금 집안일 돕기(30분/60분, 용돈벌이), 외할머니댁 심부름(1시간, 성동구 — 도보 가능), 중계동 심부름(3시간, 노원구 — 지하철 전용), 불암산 나비정원 다녀오기(3시간, 노원구 — 지하철 전용, 지각·사회성 성장 + 스트레스 해소) 네 가지가 있다.
3. 일정을 다 짰으면 "일과 시작"을 누른다 — 시작하면 더는 바꿀 수 없고, 화면이 자동으로 **지도**로 바뀐다. 이동은 항상 **방향키(↑↓←→ 또는 WASD) 또는 지도 위 버튼**으로 직접 걷는 것으로 시작한다(목적지 도착 반경 20m 안에 들어오면 자동으로 다음 블록으로 넘어감, 걷는 동안 체감 속도는 실시간 1초 = 게임 1분). 걷다가 버스정류장(원형 "B" 배지 + 정류장명으로 지도에 항상 표시)이나 지하철역의 반경 안에 들어오면 그 자리에서 멈추고 "~ 도착 — 어디로 갈까요?" 창이 뜬다 — 요금(450원)을 내고 다른 정류장/역을 고르면 그곳까지 빠르게 이동한 뒤 다시 도보가 이어지고, "그냥 걷기"를 고르면 타지 않고 계속 걷는다. 같은 정류장/역에 서 있는 동안은 다시 묻지 않는다. 수업·학원 수업 시간 자체는 조작 없이 자동으로 빨리 감기된다.
4. 목적지로 가던 중이라도 캐릭터를 집 쪽으로 직접 걸어서 되돌아가면 "일정을 취소하고 집에 들어갑니다" 확인창이 뜬다. **아니오**를 누르면 가던 길을 계속 가고, **예**를 누르면 그날 남은 일정이 전부 취소되고 집에서 할 활동(집안일 돕기 등) 하나를 고르거나 "그냥 쉬기"를 선택한 뒤 하루가 마무리된다.
5. 학교 도착이 09:00을 넘기면 지각 처리되고(버스·지하철 구간도 도착이 블록 시작시각보다 늦으면 동일하게 지각 처리), 학원을 다녀오면 그 학원 카테고리의 능력치가 오른다. 허기는 급식·저녁밥으로 회복되고, 기력은 학원 활동으로 깎이고 휴식으로 회복된다. 걷는 동안 너무 오래 헤매거나 교통비가 부족해 버스/지하철을 못 타면 지각할 수 있다. 학교 블록을 아예 빼면 그날은 등교하지 않는다.
6. 하루가 끝나면 날짜·Day 카운터가 다음 날로 넘어가고, 시간표는 그날이 평일이면 "학교만 있는" 기본 상태로, 주말·공휴일이면 빈 상태로 초기화되어 다음 날 일정을 다시 짤 수 있다 — 능력치는 누적된다.
7. 학교·학원·활동 블록마다 스트레스가 쌓인다. **80을 넘기면 그 자리에서 몸살이 나서 그날 남은 일정이 전부 취소**되고 바로 귀가한다 — 하루에 너무 많이 몰아넣지 않도록 주의. 수면으로 매일 조금씩 회복되고, 나비정원 나들이처럼 쉬는 활동은 오히려 스트레스를 줄여준다.
8. **집안일 돕기**로 번 돈은 **상점**에서 책·운동화·간식 같은 아이템을 사서 바로 스탯/허기 효과로 바꿀 수 있다. 상점은 하루 진행 중엔 구매가 막혀 있고, 일정을 짤 때만 이용 가능하다.

### 스케쥴링 · 돌발사건 · 휴대전화 (`개선필요사항_261109.md` 반영)

- **정규수업** (`data/school_schedule.json`, `data/subjects.json`): 08:30부터 등교 가능, **08:50이 넘어 도착하면 지각**. 08:30 전에 도착하면 교문 앞에서 기다린다(아침돌봄 제외). 자율독서(08:30–09:00) → 1·2교시 → 중간놀이 → 3교시 → 휴식 → 점심(급식, 허기 회복) → 4교시 → (화·수·목만) 5교시. **월·금 12:50, 화·수·목 13:40 하교.** 교시마다 요일별 시간표의 과목(국어·수학·바른 생활·슬기로운 생활·즐거운 생활·창의적 체험활동)이 진행되고 과목별 능력치가 조금씩 오른다. 지각하면 이미 지난 교시는 놓친다.
- **창의적 체험활동**은 학급 회의 → 안전 교육 → 독서 활동 → 학교 행사 준비 순서로 돌아간다. **안전 교육을 들으면 "🦺 안전교육 이수" 배지**가 생기고, 수상한 어른 돌발사건에서 안전한 선택지가 열린다.
- **방과후교육** (`data/afterschool.json`): 창의·과학 / 예체능·스포츠 / 학습·외국어의 세부 과목 22개 중 하나를 골라 끌어다 놓는다. 마지막 수업 20분 뒤 시작 → 1차시 40분 → 10분 휴식 → 2차시 40분 (월·금 13:10–14:40, 화·수·목 14:00–15:30) 고정.
- **늘봄학교** (`data/neulbom.json`): 아침돌봄 07:30–08:30(09:00까지 도착하면 지각 아님), 오후돌봄(앞 수업 끝나는 시각부터 18:00 또는 다음 일정 전까지 자동 맞춤), 저녁돌봄 18:00–20:00(저녁 간식), 방학중돌봄 08:30–17:00(방학에만, 점심 제공). 프로그램(체육·놀이 / 디지털 코딩 / 인문·예술·감성 / 기초 학습 및 탐구의 세부 10종)에 따라 시간당 성장치가 다르다. 방학 기간은 `school_schedule.json`의 `vacations`에서 설정 — 방학엔 학교가 자동으로 올라가지 않는다.
- **학원 주간 등록**: 학원정보 화면에서 학원마다 요일·시작 시각을 등록한다. 등록은 **다음 주 월요일부터 적용**되고, 적용된 수업은 매일 시간표에 자동으로 올라간다. 학원은 **운영시간 밖엔 놓을 수 없고**, 운영시간 안이지만 등록 안 한 시간에 가면 **자율학습**(집중력·성실성 +1만)을 한다. 수업이 끝나면 **하원버스로 집에 바로 가기 / 개별 이동**을 고른다.
- **돌발사건** (`data/events.json`): 지도 위를 실제로 걷는 동안 게임 1분마다 7% 확률(6분 쿨다운, 하루 최대 3번)로 발생 — 일진 어린이(싸운다: 근력 판정 / 도망간다), 곤란한 친구 돕기, 길에서 돈 줍기(100·500·1000원, `amounts`로 조정), 친구 우연히 마주치기(함께 놀기 30분 / 인사 / 모른척), 수상한 어른(안전교육 이수 시에만 "큰 소리로 거절"·"엄마에게 전화" 선택 가능, 아니면 위기 발생), 분실물 줍기(경찰서에 갖다준다 / 내가 가진다), 나비정원 삼촌 만나기(용돈·간식을 잔뜩 받고 스트레스 해소 + 사회성·자존감·기력 상승 — `locationBoost`로 **강동역 근처에서 뽑힐 확률이 12배**로 올라감), 경율이 삼촌 만나기(용돈을 받고 사회성·자존감 상승).
- **핫플레이스** (`data/hotplaces.json`): 지도에 동그란 **H** 아이콘으로 표시. 문구점(슬라임·왁뿌·포켓몬빵·포켓몬카드·문제집), 분식집(컵떡볶이·슬러시), 놀이터/공원(친구들과 술래잡기). 위치는 아직 미정이라 집 주변 900m 안에서 카카오 키워드 검색("문구"·"분식"·"어린이공원")으로 가장 가까운 곳을 잡고, 실패하면 가상 위치를 쓴다. `address`를 채우면 그 주소로 고정된다.
- **추억의 극동미라주** (`data/place_events.json`): 하왕십리극동미라주(P) 60m 안을 잠깐(실제 3초) 서성이면 "극동에 살땐 내가 참 애기였는데 벌써 초등학교 2학년이 되었어!" 같은 추억에 잠기며 스트레스 −8, 자존감 +2 (하루 1번). 근처(150m)에서 엄마에게 전화하면 "거긴 왜 갔어?" 하며 반가워하고(스트레스 −5, 자존감 +1), 아빠에게 전화하면 왜 거기까지 갔냐고 꾸짖는다(스트레스 +6). 추억 대사·효과·반경은 데이터 파일에서 바꿀 수 있다.
- **부모님 회사 방문** (`data/phone.json`의 `companyVisit`): 지하철로 5호선 강동역까지 가서 삼성메디슨(P) 300m 안에서 📱로 아빠에게 전화하면 바로 "지금 회사 앞이야, 잠깐 나와 줘!" → 부모님이 나와서 회사 식권으로 받은 간식(우유·빵·미숫가루·젤리·스타벅스 과자·바나나 중 3개)을 선물로 준다. 먹으면 기력·허기가 회복되고 스트레스가 풀린다(하루 1번, 15분). **엄마**에게 전화하면 추가로 "엄마, 빨리 퇴근하고 나랑 놀자!" 메시지도 고를 수 있다 — **논리 능력치가 높을수록** 엄마가 못 이기는 척 오늘은 일찍 퇴근하기로 하고(스트레스 감소, 자존감·사회성 상승), 낮으면 "이따 퇴근하고 꼭 같이 놀자, 사랑해"로 거절한다(`companyVisit.persuade`, 논리 기준치 20). 퇴근 후 어디로 갈지 직접 고르는 기능은 아직 미구현.
- **평일 업무시간(9~16시) 전화 톤**: 엄마·아빠는 그 시간엔 회사에 있으므로, "집으로 돌아와" 같은 말 대신 "이따 퇴근하고 보자, 사랑해~" 톤으로 대답한다(`isParentAtWork`). 추억의 극동미라주 전화(§위)도 업무시간엔 자동으로 이 톤의 대사(`workLine`)로 바뀐다.
- **휴대전화** (`data/phone.json`): 걷는 동안 지도 왼쪽 아래 📱 버튼으로 가족(엄마·아빠)·친구(등록 친구 2명, 이름은 추후 설정)·기타(외할머니, 112) 에게 전화할 수 있다. 첫 통화엔 스트레스 감소 등 효과가 있고(하루 1회), 112에 장난전화를 걸면 신뢰도가 깎인다.
### 능력치 (3분류 16종)

| 분류 | 능력치 |
|---|---|
| 🏃 신체능력 | 체력 · 근력 · 순발력 · 손재주 |
| 📚 학습능력 | 언어 · 수리 · 지각 · 논리 · 집중력 · 표현력 |
| 💖 성격/인성 | 사회성 · 성실성 · 인싸력 · 자존감 · 디지털 · 비행화 |

왼쪽 사이드바에는 **분류별 평균 3줄과 컨디션만** 간단히 보이고, 16개 전체 능력치는 **📊 능력치** 화면(프린세스 메이커 2의 상태창처럼)에서 본다. 능력치 화면에는 프로필·컨디션 한마디·가장 높은/낮은 능력, 능력치마다 설명(어떻게 올리는지), 그리고 **지난 일과 동안의 변화(+/−)**가 나온다. **비행화**는 높을수록 나쁜 값(0에서 시작, 빨간 게이지)이라 평균에서 빠진다. 컨디션 배지의 "체력"은 능력치 체력과 헷갈리지 않게 **기력(🔋)**으로 바꿨다. 과목·학원·방과후·늘봄·상점·핫플레이스·돌발사건·전화의 효과가 모두 새 능력치로 옮겨졌다 — 자세한 매핑은 `docs/design.md` §03.

### 플레이 편의 · 규칙 보강

- **자동 저장**: 하루가 끝날 때, 상점에서 살 때, 학원 등록을 바꿀 때 이 브라우저(localStorage)에 저장되고 다시 열면 이어서 한다. 능력치 화면의 "새 게임"으로 지울 수 있다. `firebase-config.js`를 설정하면(아래 "여러 기기에서 세이브 공유" 참고) 같은 세이브를 다른 기기와도 공유할 수 있다 — 설정 안 하면 지금처럼 이 브라우저에만 남는다.
- **컨디션 보정**: 허기 30 이하이거나 기력 20 이하면 능력치 성장이 절반으로 줄어든다(확률 반올림) — `docs/design.md` §04의 허기 보정을 실제로 적용.
- **지각 페널티**: 08:50이 넘어 학교에 도착하면 성실성 −1.
- **오늘의 일기 → 잠자기**: 하루 일정이 끝나면 노트 모양의 **[오늘의 일기] 2026년 3월 1일 일요일** 창이 뜬다. 그날 한 일(등교·교시별로 배운 것·급식·방과후·늘봄·학원·하원버스·돌발사건·핫플레이스·전화·버스/지하철 등)이 일기 문장으로 적히고, 아래에 오늘의 능력치 변화(오르면 초록, 내리면 빨강)와 컨디션이 붙는다. **😴 잠자기**를 누르면 화면이 잠시 어두워졌다가(Zzz…) 다음 날 "오늘 일정" 화면으로 넘어간다. 날짜는 잠자기를 눌러야 넘어가고, 그때 자동 저장된다.

아직 미구현: 교시별 퀴즈(§10), 핫플레이스 실제 위치, 친구 이름/연락처 설정, 휴대전화 상세 기능(`구현계획` 비어 있음).

## 여러 기기에서 세이브 공유 (Firebase, 선택사항)

기본값은 지금처럼 이 브라우저(localStorage)에만 저장이다. 가족이 PC·태블릿 등 **여러 기기에서 같은 이로이를 이어서 키우고 싶으면** 아래대로 무료 Firebase 프로젝트를 하나 만들고 `firebase-config.js`를 채우면 된다 — 채우지 않으면 이 섹션은 그냥 무시되고 지금처럼 동작한다.

1. [console.firebase.google.com](https://console.firebase.google.com)에서 (구글 계정으로 로그인 후) **"프로젝트 추가"** → 이름 입력(예: `roymaker`) → Google Analytics는 꺼도 된다 → 프로젝트 만들기. **카드 등록 필요 없는 무료(Spark) 요금제**로 충분하다.
2. 왼쪽 메뉴 **Firestore Database** → "데이터베이스 만들기" → 위치는 `asia-northeast3 (서울)` 추천 → **프로덕션 모드**로 시작.
3. 만들어진 뒤 **"규칙"** 탭에서 아래 내용으로 바꾸고 "게시":
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /saves/{saveId} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```
4. 왼쪽 메뉴 **Authentication** → "시작하기" → **Sign-in method** 탭 → **익명(Anonymous)** 제공업체 사용 설정. (사용자가 로그인 화면을 보는 게 아니라, 게임이 켜질 때 자동으로 조용히 처리된다.)
5. 왼쪽 위 톱니바퀴(프로젝트 설정) → 아래로 스크롤해서 "내 앱" → 웹 아이콘(`</>`) 클릭 → 앱 닉네임 아무거나 입력(Firebase 호스팅은 설정 안 함) → 등록하면 `firebaseConfig = { apiKey: ..., authDomain: ..., projectId: ..., storageBucket: ..., messagingSenderId: ..., appId: ... }` 객체가 나온다.
6. 그 6개 값을 저장소 루트의 [`firebase-config.js`](firebase-config.js)에 그대로 붙여넣고 커밋·푸시한다. (이 값들은 카카오 JS 키처럼 공개돼도 되는 값이다 — 실제 보안은 3번의 Firestore 규칙이 한다.)

이후로는 어느 기기에서 게임을 열어도 `saves/iroi` 문서 하나를 같이 읽고 쓴다 — 태블릿에서 하루를 진행하고 PC에서 열면 이어서 나온다. 네트워크가 안 되거나 설정이 잘못됐을 때는 자동으로 이 기기의 localStorage만 쓰는 것으로 조용히 넘어간다(콘솔에 경고만 남음, 게임은 끊기지 않음).

## 로컬에서 열어보기

브라우저가 `fetch`로 로컬 JSON을 읽을 수 있도록 정적 서버로 띄워야 한다 (파일을 더블클릭해서 열면 CORS로 막힘).

```
npx serve .
# 또는
python -m http.server 8787
```
