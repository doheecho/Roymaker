# 금북초등학교 새 3D 모델 제작 가이드 (단차·경사로 기준)

이 문서는 게임 「이로이의 하루」 거리 모험에 **서울금북초등학교**를 새로 넣기 위한 기준입니다.
새 모델(GLB)을 만드는 사람(또는 AI)에게 이 문서를 그대로 보여 주세요. (2026-11-26, 게임에 실제로 들어간 값)

---

## 1. 실제 모습 요약

- 학교 **동쪽 길(교문 앞길)**에서 교문까지 **오르막 진입로**가 있다. 왼쪽 초록 보행로, 가운데 빨간 포장길, 오른쪽 베이지 계단 보행로, 그 옆 금속 울타리가 있다.
- **교문부터 안쪽(운동장·교사동·농구장 등 학교 시설 전체)은 평평하다.**
- 학교 **남·남동·동쪽**은 학교가 바깥 길보다 높다. 경계는 분홍·파랑 벽화 옹벽(돌 문양)이고, 그 위에 울타리가 있다.
- 학교 **서·북쪽**은 바깥 땅이 학교보다 높다. 그쪽 옹벽은 언덕을 받친다.

## 2. 게임 좌표 기준

| 항목 | 값 |
|---|---|
| 단위 | 1 = 1m (게임 raw 단위) |
| 모델 원점(0, 0, 0) 자리 | 게임 좌표 **x = -133.9, z = -481.3** (`map_data.js`의 금북초등학교 자리) |
| 회전·크기 | 회전 0°, 크기 1 (`rotationDeg: 0`, `scaleRatio` 없음) |
| 축 방향 | +X = 동쪽(지도 오른쪽), +Z = 남쪽(지도 아래쪽), +Y = 위 |
| 높이 기준 | 게임 높이는 "우리집(금호파크힐스 113동) = 0m" 기준 |

지금 들어 있는 모델(`models/place_금북초.glb`, 첨부한 HTML의 v6.0)과 **같은 좌표계**입니다. 같은 자리에 그대로 겹쳐서 만들면 됩니다.

### 지금 모델의 주요 좌표 (모델 자기 좌표, m)

- 교문: 왼쪽 기둥 (52.6, 48.0), 오른쪽 기둥 (60.2, 48.0)
- 교문 앞길(진입로): z = 48(교문) → z = 118(아래 길)
  - 초록 보행로: [51.8, 48] [53.8, 48] [44.2, 118] [41.5, 118]
  - 빨간 길: [53.8, 45.5] [60.2, 45.5] [51.4, 118] [44.2, 118]
  - 베이지 계단 보행로: 위 [60.2, 48]~[63.5, 48], 아래 [51.4, 118]~[54.9, 118]
- 학교 외곽 울타리(교정 범위): `schoolPerimeterFencePoints` 그대로
  - [51.8, 48] [47.8, 74] [43.8, 96] [41.5, 112] [15, 111.5] [-22, 110] [-35.5, 102.5] [-42, 82] [-42, 48] [-62, 46.5] [-62, -14] [-57.5, -27.5] [-44, -35.5] [-32.5, -36.5] [-32.5, -58] [81, -58] [83, -40] [100.5, -34] [100.5, -18] [90.5, -17.5] [67.5, 46.5] [60.2, 48]

## 3. 게임에 들어간 땅 높이 (`map_data.js`의 `TERRAIN_SHAPES`)

게임은 실제 지형(GameMap.glb) 위에 아래 두 구역을 덮어씌웁니다. 모델의 바닥·길은 이 높이에 맞춰 만들면 됩니다.

### ① 금북초 교정(평지) — 높이 **20.5m** (우리집 기준)
- 범위: 위 외곽 울타리 다각형 전체 (교문 오른쪽 계단 보행로 위쪽 끝 [63.5, 47.32]까지 포함)
- `GameMap.glb` 실측 기준 금북초 교정 좌하단 최고점이 20.36m여서 교정 안 전체를 **20.5m** 평지로 통일했다.

### ② 금북초 교문 진입로(경사 · 좌측 둥근 커브)
- 범위(모델 좌표): 교문 [51.8~63.5, 48]에서 남쪽으로 직진([43.8, 96]~[55.31, 98.09])한 뒤 옹벽 끝부분에서 진행 방향 기준 좌측(동쪽)으로 약 92° 둥글게 꺾여([61.14, 103.96]~[59.50, 115.54]) 아래 도로 쪽으로 이어진다.
- 꼭짓점 높이:

| 자리 (모델 좌표) | 높이 (우리집 기준) | 모델 Y (교정 = 0 기준) |
|---|---|---|
| 교문 [51.8~63.5, 48] | 20.5m | **0.0** |
| 직선 중간 [47.8, 74] ~ [58.86, 76.09] | 17.0m | −3.5 |
| 커브 시작 [43.8, 96] ~ [55.31, 98.09] | 14.1m | −6.4 |
| 커브 구간 (1/4 → 1/2 → 3/4 → 끝) | 13.5 → 13.0 → 12.5 → 12.0m | −7.0 → −8.5 |
| 동쪽 끝 [61.14, 103.96] ~ [59.50, 115.54] | 약 11.7m (그 자리 실제 길 높이) | 약 −8.8 |

- 진입로 중심선 길이 약 67m, 오르막 약 8.8m(약 13%)이다. 아래쪽 끝은 동쪽 길(어린이 보호구역) 쪽으로 자연스럽게 이어지며, 좌측 옹벽(연두·노랑·아이들·연필 로켓·"서울금북초등학교" 벽화)과 아래·남동쪽 동측 옹벽(분홍 돌벽·파랑 물결 띠·하늘 벽화)이 자동으로 세워진다.

### ③ 경계 옹벽 (게임이 자동으로 세움)
- 구역 가장자리에서 안팎 높이가 30cm 넘게 다르면, 게임이 **돌 문양 옹벽 + 위 두겁석**을 세운다.
- 남·남동·동쪽은 학교가 높아서 옹벽이 바깥 길을 향한다. 서쪽은 바깥 언덕이 높아서 옹벽이 언덕을 받친다.
- 캐릭터는 옹벽을 넘지 못하고, 진입로 경사로로만 학교에 오르내린다.

## 4. 새 모델 만드는 방법

### 추천: 학교 전체(교정 + 진입로)를 한 모델로, `terrain: "baked"`

1. **교정은 Y = 0에 평평하게** 만든다(운동장, 교사동 1층 바닥, 농구장, 교문 등).
2. **진입로는 3번 ②의 표대로 경사지게** 만든다. 교문(z = 48)에서 Y = 0, 아래(z = 118)로 갈수록 내려가 약 −7.3~−8.5에서 끝난다.
   - 초록 보행로, 빨간 길, 베이지 계단 보행로, 울타리 모두 이 경사를 따라간다. 계단 보행로는 계단 단이 경사를 따라 내려간다.
3. **경계 옹벽은 선택**: 학교 동쪽·남쪽 바깥 면에 벽화 옹벽(분홍 돌 문양 + 파랑 띠 + 아이들 그림)을 모델로 넣고 싶으면, 그 면을 **교정 높이(Y = 0)에서 바깥 길 높이까지** 아래로 내려 만든다.
   - 동쪽 바깥 길: 약 10.5~11.7m → Y 약 −8.8~−10.0
   - 모델 옹벽이 게임 옹벽을 가려서 실제처럼 보인다(게임 옹벽은 그대로 있어도 된다).
4. 모델 바닥 밑에 땅·흙 덩어리(받침 박스)는 넣지 않는다. 게임 지형이 그 아래를 채운다.
5. 파일: `models/place_금북초.glb`(같은 이름으로 바꿔 올리면 바로 적용). 텍스처는 1024px 이하.
6. `map_data.js`의 금북초등학교 줄에 `terrain: "baked"`를 붙인다(맵 에디터로 저장해도 남는다).
   - 예: `{ id: 66, name: "금북초등학교", ..., model: "models/place_금북초.glb", rotationDeg: 0, terrain: "baked" }`
   - 이렇게 하면 게임이 모델의 **Y = 0을 정확히 그 자리 땅 높이(20.5m)**에 놓는다. 가장 낮은 점(진입로 아래 끝)을 바닥으로 맞추지 않고, 받침벽도 덧대지 않는다.

### 대안: 교정만 모델로 (진입로는 게임이 그림)
- 교정(교문 안쪽)만 Y = 0에 평평하게 만들고 진입로는 넣지 않는다. `terrain: "baked"`는 붙이지 않아도 된다.
- 진입로는 게임 지형(경사)만 보인다. 길 포장이 필요하면 맵 에디터에서 진입로를 따라 도로(어린이 보호구역 등)를 그리면 경사를 따라 붙는다.

---

## 5. 캐릭터가 걷는 높이
- 캐릭터는 **모델 표면이 아니라 3번의 땅 높이**를 따라 걷는다(교정 20.5m 평지, 진입로 경사).
- 그래서 모델의 걷는 면(교정 바닥, 진입로 포장면)은 3번 높이와 같아야 캐릭터 발이 뜨거나 묻히지 않는다.
- 계단 보행로는 캐릭터가 같은 기울기의 경사로처럼 걷는다(계단 한 단씩 오르내리지는 않는다).

## 6. 높이를 바꾸고 싶을 때
- 맵 에디터 → **⛰ 평지·경사 구역** → 구역을 누르면 오른쪽에 이름, 구역 높이, 꼭짓점별 높이가 나온다. 숫자를 고치고 **☁️ GitHub에 저장**하면 된다.
- 평지는 "구역 높이"만 정한다. 경사로는 위쪽 끝 꼭짓점에 윗 높이를 넣고, 아래쪽 끝은 비워 두면 그 자리 실제 길 높이를 따른다.
- 높이를 바꾸면 3번 표와 모델 Y 값도 같이 바뀐다(모델 Y = 그 자리 높이 − 교정 높이).
- 다른 단지·학교도 같은 방법으로 평지·경사 구역을 그리면 된다.
